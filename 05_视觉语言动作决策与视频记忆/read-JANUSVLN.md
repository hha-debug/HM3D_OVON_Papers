# JanusVLN Method

```text
JanusVLN Method
├── ① 语义与几何编码：怎样仅从 RGB 获取互补的视觉信息？
│   ├── 语义分支：Qwen2.5-VL 原生视觉编码器 → 提取物体、场景等视觉语义特征
│   ├── 几何分支：预训练 VGGT 的编码器与跨帧融合解码器 → 提取带三维几何先验的空间 tokens
│   └── 特征使用：导航使用 VGGT 内部几何表示 → 无需输入深度图、激光雷达点云或先输出三维地图
│
├── ② 双隐式记忆：怎样逐帧利用历史，而避免反复处理整个视频？
│   ├── 空间记忆：当前帧生成 Query → 与历史及当前帧的 Key、Value 做注意力 → 增量更新几何表示
│   ├── 缓存维护：保留最初 8 帧作为注意力锚点，并维护最近 48 帧 FIFO 窗口 → 限制几何缓存大小
│   └── 语义记忆：论文通过 Qwen 语言模型的 KV 机制利用历史语义；公开评测每步重新输入采样历史图像
│
└── ③ 特征融合与导航闭环：怎样把环境理解变成下一步动作？
    ├── 网格对齐：两路特征做相邻 2×2 patch 合并 → 几何特征经两层 MLP 投影至语言模型维度
    ├── 融合决策：语义特征 + 0.2 × 投影后的几何特征 → 连同导航指令输入 Qwen 语言模型
    └── 动作执行：生成 MOVE_FORWARD / TURN_LEFT / TURN_RIGHT / STOP → 执行、观察新图像并重复
```

**主要贡献：**围绕 Qwen2.5-VL-7B 与 VGGT 构建语义、几何双分支导航模型，把三维预训练模型的几何先验接入仅使用 RGB 的导航决策。关键包括：语义与空间特征的互补融合；将原本需要联合处理多帧的 VGGT 改造成利用历史 KV 的流式几何编码器；通过起始窗口与最近窗口维护空间及语义的隐式记忆。其新增设计主要集中于环境表示和历史信息更新，动作预测仍由微调后的语言模型完成。“解耦”指架构上的分支分工，论文没有证明两种表示在数学上完全独立。

**输入：**自然语言导航指令，以及第一人称、前向单视角 RGB 图像流。模型不需要 RGB-D 的深度通道、激光雷达点云、全景图或里程计作为导航策略输入。VGGT 的三维能力来自预训练的几何知识和跨帧交互；应区分“VGGT 预训练使用三维监督”与“JanusVLN 推理只接收 RGB”。论文中的深度图与点云用于展示几何 tokens 所含的信息，不是导航时额外输入的传感器数据。公开评测在 VLN 任务中读取自然语言指令，在 ObjectNav 配置中读取目标类别。

**历史：**论文将历史记忆定义为 Transformer 的 Key、Value 表示，分别用于空间几何与视觉语义。空间分支交替执行单帧注意力和全局跨帧注意力：当前帧 tokens 产生 Query，历史缓存与当前帧新产生的 KV 拼接为注意力读取对象。缓存保留最初 8 帧及最近 48 帧，最近窗口按 FIFO 更新；超过窗口的中间历史会被移出，不能理解为保存了完整、永久的全局地图。附录 B 说明，Qwen 语义侧的 KV 读取发生在语言模型内部，而不是为视觉编码器另建一个独立的循环记忆网络。

**论文与公开代码的区别：**截至 2026-10-15 核对的官方 `main` 分支中，`evaluation.py` 在每个 episode 开始时清空 `past_key_values_vggt`，随后由模型跨导航步更新 VGGT 缓存；每步只把当前图像送入 VGGT。Qwen 则重新接收采样的历史图像与当前图像，默认 `num_history=8`，历史较长时通过 `np.linspace` 均匀选取，总计最多 9 张图像。该调用路径没有显式把上一导航步的语言模型 KV 传入下一次 `generate()`，因此不能将公开评测概括为“两路均跨步复用 KV”。模型代码还将当前几何分支特征重复到语义图像 tokens 的数量后相加，应与论文逐帧融合的示意区分。评测程序的 `rgb_list` 仍保留原始历史图像，几何缓存固定大小不等于整个程序的内存占用固定。[评测代码](https://github.com/MIV-XJTU/JanusVLN/blob/main/src/evaluation.py)、[模型代码](https://github.com/MIV-XJTU/JanusVLN/blob/main/src/qwen_vl/model/modeling_qwen2_5_vl.py)。

**输出：**

- 导航模型：自回归生成一个基本动作字符串，候选为 `MOVE_FORWARD`、`TURN_LEFT`、`TURN_RIGHT`、`STOP`。标准评测不要求输出 frontier 坐标、航点序列或分析文本。
- 导航层：将字符串映射为 Habitat 动作编号并调用 `env.step()`；论文定义每次前进 0.25 m，每次左右转向 30°。执行后重新观察，再进行下一步预测。这条标准模拟评测路径没有额外的候选箭头生成器、PointNav 执行器或 A* 路径规划器。
- 停止判断：`STOP` 与移动动作由同一个导航模型生成，没有 CompassNav 那样独立的 Stop Agent。公开评测将无法识别的输出及达到最大步数的情况映射为停止；这属于实现中的回退处理。

**训练：**基于 Qwen2.5-VL-7B-Instruct 与预训练 VGGT-1B，冻结语义视觉编码器和 VGGT，微调语言模型与几何投影层。论文报告训练 1 epoch，语言模型学习率为 2×10⁻⁵，投影层为 1×10⁻⁵；模型代码使用自回归交叉熵损失学习动作输出。基础版使用标准 R2R-CE/RxR-CE 数据，额外数据版加入约 155K 条 ScaleVLN 轨迹（约 9207K 图像-动作对），以及通过 DAgger 收集的约 14K 条轨迹（约 1485K 图像-动作对）。DAgger 为模型偏离专家路径后遇到的状态补充专家动作监督，不是 GRPO 等强化奖励优化。公开 Base 训练脚本使用 BF16、AdamW、DeepSpeed ZeRO-3、梯度检查点、每设备 batch size=1、梯度累积 8、warmup ratio=0.03、余弦学习率和 weight decay=0.01；脚本的 4–8 帧训练视频配置应与推理时的 8+48 帧缓存配置区分。这些脚本参数不能直接当成论文全部实验的统一配置。[训练脚本](https://github.com/MIV-XJTU/JanusVLN/blob/main/scripts/train.sh)。

**特征融合与增量更新：**设语义特征为 `S_t`、几何特征为 `G_t`，相邻 2×2 patch 合并后的特征记为 `S'_t`、`G'_t`，论文采用 `F_t = S'_t + λ × MLP(G'_t)`，默认 `λ=0.2`。两层 MLP 将几何特征投影到语言模型的隐藏维度，融合后的视觉 tokens 与指令文本共同参与动作预测。空间注意力可以理解为 `Attention(Q_t, [K_history; K_t], [V_history; V_t])`：只为新帧计算新的表示，再读取可保留的历史 KV。KV 复用、滑动窗口和加权相加均有已有技术基础，论文的具体贡献在于将其用于语义与几何互补的 RGB 流式导航，并验证几何预训练的收益。

**训练算力与推理部署（论文与作者答复）：**论文本身未报告训练 GPU 数量和总时长。官方仓库作者在 Issue #3 中答复使用 64 张 H20，约 31 小时，对应约 1984 H20 GPU·小时；该估算对应作者描述的一次训练，不包含数据生成及所有消融实验，也未明确区分 Base/Extra。Issue #5 中作者答复单卡推理约需 40 GB 显存，并指出单卡遍历完整仿真验证集较慢；这不是所有输入长度和部署设置下的最低显存保证。论文真机实验使用 Unitree Go2、Insta360 X5 前向 RGB 相机及远程 A10 GPU 服务器，未报告该真机配置的峰值显存和完整控制链路时延，不能把 Issue 中的 40 GB 直接视为 A10 的测量结果。Table 5 的几何处理耗时在 8 帧下由 268 ms 降为 82 ms，在 32 帧下由 1549 ms 降为 149 ms；48 帧缓存配置为 195 ms。这些是 VGGT 与缓存方案的处理比较，不能直接等同于包含 Qwen 动作生成、通信和机器人执行的端到端耗时。[训练算力答复](https://github.com/MIV-XJTU/JanusVLN/issues/3#issuecomment-3375195701)、[推理显存答复](https://github.com/MIV-XJTU/JanusVLN/issues/5#issuecomment-3466168233)。

**评测：**主要任务为 VLN-CE，在 R2R-CE 与 RxR-CE 的 Val-Unseen 上报告 NE、OS、SR、SPL、nDTW 等指标。无额外数据的 JanusVLN* 在 R2R 上 SR/SPL=52.8%/49.2%，在 RxR 上为 51.4%/44.3%；额外数据版在 R2R 主表中为 60.5%/56.8%，在 RxR 上为 56.2%/47.5%。HM3D-OVON 在附录 Table 6 的 Val-Unseen 上为 **SR=44.9%、SPL=31.7%**；该表没有报告 Val-Seen 与 Seen-Synonyms，也未细述该项评测是否额外采用了任务专用训练。真机定量实验使用 25 条指令，每条重复 3 次，停止位置距离目标不超过 1 m 视为成功；论文报告空间理解任务相对去掉空间分支的变体有明显提升。真机 1 m 成功判据应与各仿真基准的判据区分。

**消融与配置说明：**Table 3 中，完整模型 SR/SPL 为 52.8%/49.2%；去掉空间记忆后为 47.0%/40.9%，去掉语义记忆后为 45.5%/40.0%，两者都去掉后为 24.8%/16.8%。去掉语义记忆的 SR 下降是 7.3 个百分点，正文的 13.8% 对应相对降幅。Table 4 中，无额外编码器、DINOv2、SigLIP 2、随机初始化 VGGT、预训练 VGGT 的 SR 分别为 47.0%、47.5%、47.9%、47.2%、52.8%，支持三维预训练先验带来互补收益，而不仅是额外模型容量。Table 5 中，去掉起始窗口后 48 帧配置的 SR/SPL 从 52.8%/49.2% 降至 51.0%/47.5%；缓存效果在 48 帧附近趋于饱和。Table 7 中，`λ=0.2` 的加权相加优于所测试的拼接与交叉注意力融合。Table 8 中，加入 ScaleVLN、加入 DAgger、同时加入二者的 SR 分别为 55.5%、56.4%、60.5%。R2R 额外数据版的 SPL 在主文 Table 1 写为 56.8%，在附录 Table 8 写为 56.6%，原文未解释差异，应按各表原值记录。作者报告的主要失败包括偏航后自我纠错不足及提前停止，并推测 VGGT 特征缺乏真实尺度可能导致距离估计不准；这是作者的解释，不是已单独验证的因果结论。
