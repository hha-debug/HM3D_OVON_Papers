## 如何理解交叉方法

- TANGO 的主线是生成程序并调度工具，探索部分采用语义地图方法；因此主目录为大模型规划，交叉标签含前沿探索与特征记忆。
- MSGNav 的核心环境表示是多模态三维场景图，也用 VLM 闭环推理；放在三维表征类，保留大模型规划标签。
- CompassNav 用 VLM 选择视觉动作候选，同时使用 SFT/GRPO。它归入视觉语言动作决策，交叉标签含模仿与强化学习；它不因类名含视频记忆而被解释成使用长视频历史。
- OmniNav 采用快慢模型：慢规划选择子目标，快策略生成连续 waypoints；属于视觉语言动作模型，并带规划与探索标签。
- HM3D-OVON 包含 DAgRL 等学习式基线，SG3D 包含 SG-LLM；两篇主贡献是任务与数据，因此主目录仍为基准。

- SuperNav 的主线是多模态大模型调用工具、按需加载技能并管理任务进度；与 TANGO 同属大模型规划与工具调用。其 MLLM 无导航专项微调，可选的学习式运动执行器单独训练。
