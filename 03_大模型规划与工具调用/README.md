# 大模型规划与工具调用

大模型负责组合程序或高层步骤，检测、匹配、探索、移动和问答由专门模块完成。

主类别采用主要技术贡献；文件名中的年份与会议只用于识别原文件。

| 论文 | 核心机制 | 交叉标签 |
|---|---|---|
| [TANGO](2025_CVPR_TANGO.pdf) | LLM 生成调用 primitives 的程序，Interpreter 执行；探索和特征地图是被调度的模块。 | 语义地图与前沿探索；可重查询特征记忆 |
| [SuperNav](SuperNav.pdf) | 预训练多模态大模型通过智能体循环按需读取技能、选择视觉目的地并调用导航工具；核心贡献是工具接口和持续任务管理。 | 多模态视觉点导航；技能指引与工具执行；任务进度与上下文管理；闭环目标核验与恢复 |
