# SuperNav Method

```text
SuperNav Method
├── ① 智能体决策：怎样持续理解请求并选择行动？
│   ├── 预训练 MLLM：请求 + 四方向 RGB + 历史／进度 → 工具调用
│   ├── Navigation Skills：按需读取 Markdown → 搜索、复核、恢复、完成指导
│   └── Agent loop：Codex CLI + MCP → 执行工具 → 返回反馈 → 下一轮决策
│
├── ② 运动执行：怎样把图像中的目标点变成移动？
│   ├── 统一接口：视角 + 归一化图像点 [u, v]（0–1）→ 目的地
│   ├── Geo-based Executor：深度 + 标定 + 位姿 → 反投影 → 路径规划与跟随
│   └── Learned Executor：标记目标点的参考图 + RGB 历史 → 位移增量／停止信号 → 执行与重规划
│
└── ③ 任务与历史管理：怎样保留证据并结束任务？
    ├── 目标记录：保存待完成／已找到目标，持续更新任务进度
    ├── 上下文管理：移除后续请求中的旧图数据，保留文本历史和图像路径
    └── 任务终止：MLLM 判断完成或受阻 → 报告 achieved／blocked → 关闭会话
```

**主要贡献：**以智能体运行框架组织预训练 MLLM 的持续导航决策；统一视觉点接口支持替换运动执行器，结合 Skills、任务进度和上下文管理处理不同请求。

**输入：**用户请求（单目标、有序多目标或高层需求）、系统提示、四方向 RGB、文本历史和任务进度交给 MLLM。几何式执行器另用深度、相机标定、位姿和导航几何；学习式执行器接收标记目标点的参考图及近期 RGB 历史。

**历史：**文本记录保存已检查区域、候选线索和失败尝试；目标记录保存待完成与已找到目标。旧图保存在工作区，后续模型请求移除其图像载荷，需要时可按路径重新读取；学习式执行器另维护局部 RGB 历史。

**输出：**

- MLLM：工具调用及参数（所选视角、图像点坐标等）、目标进度与完成／受阻判断。
- 运动执行器：移动动作；导航工具返回四方向 RGB、执行状态和简要诊断信息。
- 终止工具：记录 achieved／blocked 并关闭会话；任务成功由独立评测判定。

**训练：**MLLM 使用预训练模型，无导航专项微调；主实验采用 GPT-5.6 Terra，模型替换实验采用 GPT-6 Astra（medium）。几何式执行器采用几何规划，无需训练导航策略；学习式执行器在仿真专家轨迹上通过监督模仿训练，并联合微调 DINOv2 视觉骨干。

依据：正文第 3 节；运行与工具实现见附录 A.1–A.2，学习式执行器与训练见附录 C。
