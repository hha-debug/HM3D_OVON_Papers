# MSGNav Method

```text
MSGNav Method
├── ① 三维感知：怎样把连续观测变成场景记忆？
│   ├── RGB-D + 位姿：YOLO-World 检测、SAM 分割、CLIP 特征 → 三维物体节点
│   ├── 物体更新：空间与视觉匹配 → 融合重复观测，维护全局物体 ID、类别、点云与房间信息
│   └── M3DSG 图像边：同框且距离足够近的物体对 → 保存共同观测图像，建立边与图像的双向索引
│
├── ② 目标与探索决策：怎样从场景记忆中找目标？
│   ├── KSS：压缩图摘要 → VLM 选择相关节点 → 贪心选择图片覆盖相关边，形成关键子图
│   ├── VLM 推理：结合目标、子图图像证据、前沿图像与历史决策 → 选择目标物体或探索前沿
│   ├── AVU：VLM 从图像证据中提出新词汇 → 扩展检测词表，补充场景语义
│   └── CLR：保存历史决策，结合新观测更新的场景记忆 → 反馈后续推理
│
└── ③ 导航执行：找到目标后应该站在哪里？
    ├── 未找到目标：前往选定前沿 → 获取新观测，继续更新场景图
    └── 已选定目标：VVD 在目标周围采样可通行视点 → 计算目标点云可见比例 → 选择最终导航点
```

**主要贡献：**以物体对索引同框图像作为 M3DSG 的关系边，建边时无需调用 VLM 生成文字关系；通过 KSS 按任务筛选视觉证据，并通过 VVD 优化目标已定位后的最终视点。AVU 与 CLR 分别支持在线词表扩展和历史决策反馈。

**输入：**目标类别、自然语言描述或参考图像，以及 RGB-D 图像流与位姿；VLM 接收目标相关子图及图像证据、探索前沿图像和历史决策。

**历史：**M3DSG 保存已观测物体的语义、几何和共同观测图像；决策记忆保存历史目标或前沿选择；检测词表以 ScanNet-200 初始化，并随探索扩展。

**输出：**

- VLM：目标物体 ID 或探索前沿选择，以及建议新增的词汇。
- VVD：目标周围可通行候选视点中，目标点云可见比例最高的导航坐标。
- 规划与执行模块：前往选定前沿或目标视点的移动动作。

**训练：**无需导航任务专属训练或微调；使用预训练的 YOLO-World、SAM、CLIP 与 VLM。正文主要使用 GPT-4o，补充材料还评估了 Qwen-VL-Max；场景图、词表和决策记忆在推理过程中更新。

**推理算力（论文配置）：**实验使用 NVIDIA A800-SXM4-40GB，视觉基础模型推理约需 8–10 GB 显存；上述显存需求对应 VLM 通过 API 调用的配置，本地部署大模型需要额外显存（见补充材料第 6.1 节）。

**评测：**正文主实验为 GOAT-Bench 的 Val Unseen 和 HM3D-ObjNav（6 个目标类别）；补充材料仅报告 HM3D-OVON 的 Val Seen，SR 为 48.3%、SPL 为 27.0%，未报告 Val Seen Synonyms 和 Val Unseen。Val Seen 指目标类别在导航训练划分中出现过，评测场景与物体实例仍与训练划分分离。
