# D3D-VLP Method

```text
D3D-VLP Method
├── ① 三维感知：怎样把连续观测变成空间表示？
│   ├── Dynam3D：RGB-D + 位姿 → 持续更新多层次 3D Memory
│   ├── 3D tokens：全景图像块、物体实例、空间区域
│   └── 统一空间嵌入：在智能体坐标系中对齐 3D tokens 与航点
│
├── ② 统一决策：怎样把计划、目标和动作关联起来？
│   ├── 3D-VLM（NVILA-Lite-2B）：自回归生成计划 → 目标 → 航点 → 回答
│   ├── Grounding Head：隐表示与 3D tokens 匹配 → 具体目标
│   ├── Waypoint Predictor：提出候选航点；Navigation Head：选择航点 → 控制器执行
│   └── CoT Memory：任务进展、目标、已走轨迹 → 反馈后续决策与动态重规划
│
└── ③ 协同训练：怎样利用不完整的标注？
    ├── 混合数据：约 1000 万样本，包含约 17.5 万全标注样本和大量部分标注样本
    └── SLFS：生成完整 CoT，仅对已有标注计算损失 → 共享模型联合学习
```

**主要贡献：**动态 3D CoT 统一规划、三维目标定位和导航，通过记忆反馈支持重规划；SLFS 利用部分标注数据联合训练。

**输入：**用户指令、RGB-D 图像流与位姿；3D-VLM 接收指令、多层次 3D tokens 及空间嵌入、候选航点和 CoT 历史。

**历史：**3D Memory 保存已观测环境的语义与几何信息；CoT Memory 保存已完成子指令、目标 token 及位置、已走航点。

**输出：**

- 3D-VLM：后续计划、三维目标 token、选定航点、自然语言回答。
- 航点预测器：附近可通行的候选航点。
- 动作控制器：前往选定航点的移动动作。

**训练：**以预训练 NVILA-Lite-2B 为基础，从约 1000 万混合样本中抽样，使用 SLFS 掩码自回归损失联合训练；含导航任务的样本在模拟器中结合 DAgger 在线训练。

**训练算力（论文配置）：**4 张 NVIDIA RTX 6000 Ada GPU，训练 100K episodes（10 万个回合），耗时约 14 天，总 batch size 为 8（见论文第 4.1 节）。
