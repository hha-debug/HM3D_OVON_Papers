# MTU3D Method

```text
MTU3D Method
├── ① 在线三维表征
│   ├── FastSAM + DINO：图像分区、二维特征提取 → 区域级视觉表征
│   ├── 深度 + 位姿 → 世界坐标点云；稀疏卷积 U-Net → 区域级三维表征
│   ├── Query Proposal：融合二维与三维特征，经查询解码器生成对象框、掩码、特征和置信度
│   └── Spatial Memory Bank：三维框 IoU 匹配 → 特征与几何融合、掩码取并集 → 全局对象记忆
│
├── ② 统一决策
│   ├── 占据地图：已知与未知区域的边界 → 前沿点；MLP → 前沿查询
│   ├── CLIP：文字或图片目标 → 目标嵌入；类型嵌入区分对象查询与前沿查询
│   ├── Spatial Reasoning Transformer：目标 + 对象查询 + 前沿查询 → 统一候选打分
│   └── 选择最高分候选：对象 → 目标定位；前沿 → 探索位置；路径规划器执行移动并获取新观测
│
└── ③ 分阶段训练
    ├── 轨迹数据：ScanNet 真实 RGB-D 序列 + HM3D 模拟轨迹，联合视觉定位与探索数据
    ├── 探索采集：混合专家与随机前沿选择 → 覆盖不同探索状态，降低过拟合
    └── 感知训练 → 冻结查询生成模块 → 百万级轨迹 VLE 预训练 → 特定导航任务微调
```

**主要贡献：**从 RGB-D 流在线建立对象级三维记忆，将对象定位与探索前沿选择统一为候选查询打分；通过 Vision-Language-Exploration（VLE）预训练支持多种目标形式与持续导航。

**输入：**文字目标（类别、描述、任务步骤或问题）、参考图片、RGB-D 图像流与相机位姿；决策模型接收目标嵌入、全局对象查询、前沿查询及空间信息。

**历史：**Spatial Memory Bank 保存已观测对象的三维框、实例掩码、解码特征、开放词汇语义特征和置信度；占据地图记录已占据、未占据和未知区域，并用于更新探索前沿。

**输出：**

- 对象感知模块：世界坐标系中的三维对象框、实例掩码、对象特征与置信度。
- 空间推理模块：选定的对象查询或前沿查询及其对应空间位置。
- 路径规划器：前往选定位置的局部轨迹与移动动作。
- 问答任务：MTU3D 提供探索轨迹与观测视频，回答由外接 GPT-4o/V 生成。

**训练：**阶段 1 使用三维框 IoU 损失、掩码与置信度的二元交叉熵损失、开放词汇特征的余弦相似度损失训练感知模块；随后冻结查询生成模块。阶段 2 使用视觉定位与探索轨迹，以二元交叉熵训练统一候选打分；阶段 3 使用相同决策目标进行任务特定微调。三个阶段分别训练 50、10、10 个 epoch（见论文第 3.4、4.1 节）。

**训练算力（论文配置）：**4 张 NVIDIA A100 GPU，论文报告约 164 GPU·小时（见论文第 4.1 节；GPU·小时是计算量单位）。

**推理参考（论文测试）：**在 NVIDIA RTX 3090 Ti 上，查询生成约 192 ms、空间推理约 31 ms，报告帧率为 3.4 FPS、模型参数量为 266M；结果为多帧、多回合的 5 次运行平均值（见论文第 4.3 节、表 7）。
