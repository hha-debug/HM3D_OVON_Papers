# 论文与编码器关系图

本图依据上一级目录的《论文编码器关系总表.md》，覆盖 18 篇独立论文与 PQ3D、Dynam3D 两篇基础依赖。

- [交互关系图](论文编码器交互关系图.html)：可搜索、缩放、跳转论文。点击模块可查看输入、输出、功能、使用者与来源。
- [SVG 矢量图](论文编码器详细关系图.svg)：适合放大、排版或导入矢量软件。
- [完整 PNG](论文编码器详细关系图.png)：3600 像素宽的静态关系图。
- [编码器功能说明](编码器功能说明.md)：42 个模块的逐项功能及论文来源。
- [结构化关系数据](关系图数据.json)：包含 20 篇论文、42 个模块、9 条论文继承关系及明确的后端内部依赖。

图分为三部分：已确认的论文继承链、逐篇感知–表征–决策流程、编码器和模块功能索引。

E01–E16、E21–E22 是输入编码器，E17–E20 是三维表征/query 模块，P01–P16 是检测、分割、匹配或图文工具，A01–A04 是连接与适配模块。图中未将这些类型合并为同一种编码器。

训练状态按论文与训练阶段记录。原文未明确的配置保持“未明确”；闭源 VLM 内部编码器不补猜。基准中的作者策略、对照基线与数据生成调用在图内分别注明。

更新：编辑 `graph_data.py` 后运行 `python build_graph.py`。字体使用 Windows Microsoft YaHei。`render_preview.mjs` 用本地 Chrome 生成交互版预览并检查搜索、节点详情及作用范围。
