# 编码器与感知模块功能说明

对应：[详细关系图](论文编码器详细关系图.svg) · [交互关系图](论文编码器交互关系图.html) · [原始总表](../论文编码器关系总表.md)

本图按论文逐一记录训练状态；以下定义模块功能。检测、分割、投影、适配与决策模型不合并为同一种编码器。

## 输入编码器

| 编号 / 模块 | 输入 → 输出 | 对应功能 | 使用者与边界 |
|---|---|---|---|
| E01 SigLIP 图像 / 文本编码器 | RGB / 目标文字 → 对齐的图文特征 | 将观察和目标类别编码到可比较的语义空间，供策略理解开放词汇目标。 | OVSegDT、HM3D-OVON（作者基线）。图像编码与文本编码是两路；在 OVON 与 OVSegDT 中冻结。 |
| E02 CLIP / OpenCLIP | 图像 / 文字 → 语义向量或 patch 特征 | 支持图文相似度、物体外观匹配、目标编码，或作为三维特征场的视觉基础。 | MTU3D、MSGNav、TANGO、PQ3D、Dynam3D、GOAT-Bench（作者基线）、SG3D / SG-LLM（导航基线）、D3D-VLP（经 Dynam3D 后端）。各论文使用的模型尺寸、权重和提取层不一定相同。 |
| E03 DINO（MTU3D） | RGB → 像素 / patch 视觉特征 | 为区域与物体 queries 提供外观特征，再与三维几何特征融合。 | MTU3D。正文引用 DINO / DINOv2；未确定具体版本，不等同于 DINOv3。 |
| E04 DINOv3 | RGB → 自监督视觉 patch 特征 | 提取图像语义与空间外观特征，随后压缩为视觉历史 tokens。 | SoftNav、AstraNav-Memory。SoftNav 与 AstraNav 冻结该骨干；型号不强行统一。 |
| E05 EVA-CLIP | 视频单帧 RGB → 视觉 patch tokens | 编码 Uni-NaVid 的逐帧视频观察，为当前、短期和长期记忆提供视觉特征。 | Uni-NaVid。记忆压缩由后续池化 / token 合并完成。 |
| E06 Qwen2.5-VL 原生视觉编码器 | 图像 / 输入视觉特征 → 视觉 tokens | 提供 VLM 的图像语义表示，供语言主干进行目标理解和导航决策。 | AstraNav-Memory、JanusVLN、OmniNav、CompassNav。AstraNav 用压缩特征接入 ViT；SoftNav 的 DINOv3 输入路径不画成原生 ViT 编码。 |
| E07 VGGT encoder + fusion decoder | 多帧 RGB → 空间几何特征 | 提取跨视角空间先验，补充 Qwen 的语义特征；JanusVLN 用其构建空间隐式记忆。 | JanusVLN。Janus 使用空间特征，不等同于直接建立显式三维场景图。 |
| E08 PointNet++ | 三维点集 → 点云 / 区域特征 | 编码局部几何及点集上下文，支持三维物体理解、grounding 或类别预测。 | PQ3D、SG3D / SG-LLM（3D-VG / LLM 对照）。SG3D 明确用于对照基线；SG-LLM 的最底层 backbone 未明确。 |
| E09 稀疏卷积 U-Net | 稀疏三维点 / 体素 → 多尺度几何特征 | 编码三维几何结构，供区域 pooling、实例 queries 与三维分割使用。 | MTU3D、PQ3D。PQ3D 为 Mask3D 风格；MTU3D 使用自身在线感知设置。 |
| E10 OpenSeg / OpenScene 多视角路径 | 图像像素特征 → 三维 segment 视觉特征 | 将二维语义特征反投影并跨视角汇聚，与点云、体素特征在三维区域上对齐。 | PQ3D。原始 PQ3D 的输入路径；不直接复制到 SoftNav 组件清单。 |
| E11 BERT-base-uncased | 目标句子 → 句子语义向量 | 编码 GOAT-Bench LanguageNav 中描述目标实例的自然语言。 | GOAT-Bench（作者基线）。冻结；后续 GRU 策略负责导航。 |
| E12 CroCo-v2 | 观察图像 / 目标图像 → 跨视角视觉特征 | 建立具有跨视角一致性的图像表征，用于实例图像目标的识别和接近。 | GOAT-Bench（作者基线）。GOAT-Bench ImageNav 技能使用冻结模型。 |
| E13 ResNet9（mask 分支） | 目标二值 mask → mask 特征向量 | 把目标的位置、形状和占据范围编码为 OVSegDT 策略输入。 | OVSegDT。这是新增可学习分支，不是 SigLIP 的图像编码器。 |
| E14 ResNet18（普通 RGB） | RGB → 视觉特征 | 为 HM3D Semantics 的模仿学习策略提供当前观察特征。 | HM3D Semantics（作者基线）。该基线从随机初始化开始；具体冻结范围未明确。 |
| E15 ResNet50（普通视觉 / 深度） | 深度或 RGB-D → 视觉 / 几何特征 | 编码可通行环境和当前观察，供 PointNav 或 ObjectNav 循环策略预测动作。 | MOPA、HM3D Semantics（作者基线）。MOPA 使用深度版本；HM3D Semantics 的用途随基线变化。 |
| E16 CLIP ResNet50（CLIP-RN50） | RGB → 图文预训练的视觉语义特征 | 编码 GOAT-Bench 中的导航观察，再与目标特征、位姿一起输入 GRU。 | GOAT-Bench（作者基线）。不同于普通 ResNet50；两者不能视为同一训练权重。 |
| E21 SemExp 语义地图 CNN | 俯视语义 / 占据地图 → 地图特征 | 编码已探索区域、障碍和物体分布，再结合目标类别预测下一步探索位置。 | HM3D Semantics（作者基线）。HM3D Semantics modular 基线训练探索策略；不是 RGB 图像编码器。 |
| E22 PointNav 深度视觉编码路径 | 当前深度图 → 局部环境特征 | 让低层导航策略结合 waypoint 的相对距离和方向选择移动动作。 | VLFM、OpenFrontier、TANGO。VLFM / TANGO 正文未细分骨干型号；OpenFrontier 复用 VLFM 权重，不补猜 ResNet 版本。 |

## 三维表征 / query 模块

| 编号 / 模块 | 输入 → 输出 | 对应功能 | 使用者与边界 |
|---|---|---|---|
| E17 PQ3D 风格 query decoder | 场景特征 + 提示 → 更新后的实体 queries | 通过场景 / 提示 cross-attention 与空间 self-attention 汇聚任务相关实体信息。 | MTU3D（架构借鉴）、PQ3D。MTU3D 借鉴解码结构；不是完整复制原始 PQ3D 权重。 |
| E18 MTU3D / PQ3D 系在线后端 | RGB-D + 位姿 → 物体 / frontier queries | 持续提取和合并三维物体特征，并把物体与探索前沿组织为统一实体表征。 | SoftNav。SoftNav 冻结调用；后端权重按基准选择，策略 projector / LoRA 跨基准共享。 |
| E19 Dynam3D encoder | CLIP 特征 + 深度 / 位姿 → patch–instance–zone | 把二维特征投到三维，聚合为物体与区域 tokens，并渲染局部全景特征。 | D3D-VLP、Dynam3D。底层 CLIP + FastSAM + 三维聚合；D3D-VLP 是否更新该 encoder 未明确。 |
| E20 SG-LLM 空间 Transformer | 三维物体实例 → 带空间上下文的 object tokens | 把场景中的物体组织成语言主干可接收的三维实体表征，支持顺序指代与 grounding。 | SG3D / SG-LLM（SG-LLM）。原文未明确最底层对象特征 backbone 和完整冻结范围。 |

## 检测、分割与图文工具

| 编号 / 模块 | 输入 → 输出 | 对应功能 | 使用者与边界 |
|---|---|---|---|
| P01 YOLO-World | RGB + 检测词表 → 类别与物体框 | 开放词汇物体检测；MSGNav 用它建立物体节点并识别房间相关语义。 | MSGNav。完整检测器，不与独立视觉特征编码器等同。 |
| P02 YOLOv7 | RGB → COCO 类物体框 | 在原 VLFM 中识别 COCO 目标类别，触发目标接近阶段。 | VLFM。固定类别检测器；非 COCO 类使用 GroundingDINO。 |
| P03 GroundingDINO | RGB + 目标文字 → 目标框 | 语言条件的开放词汇检测，为 VLFM 的非 COCO 目标提供定位。 | VLFM。GroundingDINO 检测器与 DINO 自监督特征骨干是不同组件。 |
| P04 YOLOE | RGB + 目标类别 → 目标分割 mask | 部署时为 OVSegDT 提供预测目标 mask，替代训练场景中的真值 mask。 | OVSegDT。论文训练的是接收预测 mask 的导航策略，未证明其微调 YOLOE。 |
| P05 OWLv2 | RGB + 类别 / 文字 → 开放词汇框 | 确认目标是否出现；用于 TANGO 检测工具和 OVON 的 OD / VLFM 对照。 | TANGO、HM3D-OVON（作者基线）。OVON 修改版 VLFM 使用它；原 VLFM 使用别的检测器。 |
| P06 DETR | RGB → 类别与物体框 | TANGO 用它检测 COCO 类物体，为程序中的 detect 工具提供结果。 | TANGO。与 OWLv2 共同组成不同类别下的工具选择。 |
| P07 Faster R-CNN | RGB → 指定类别物体框 | MOPA 的 MultiON 检测模块，识别圆柱或自然物体目标。 | MOPA。在对应 MultiON 设置中离线微调；不是统一冻结的检测器。 |
| P08 Detic | RGB + 类别词汇 → 语义检测 | 为物体导航和语义 / 实例地图提供类别检测结果。 | MOPA、GOAT-Bench（作者基线）。MOPA ObjectNav 冻结调用；GOAT 模块化基线也使用它。 |
| P09 SAM | RGB + 物体提示 → 实例 mask | 分离检测框对应的物体像素，供深度反投影和三维物体节点构建。 | MSGNav。MSGNav 的实例分割组件。 |
| P10 Mobile-SAM | RGB + 检测框 → 目标轮廓 mask | VLFM 用目标轮廓与深度估计目标位置，生成接近 waypoint。 | VLFM。轻量分割组件。 |
| P11 FastSAM | RGB → 图像区域 / 实例 masks | 给特征 pooling 和三维实例聚合提供区域分组。 | MTU3D、Dynam3D、D3D-VLP（经 Dynam3D 后端）。MTU3D 与 Dynam3D 使用；后续物体特征由其他编码 / 聚合模块产生。 |
| P12 SAM3 | RGB + 目标概念 → 目标 mask | OpenFrontier 用它提出候选目标，之后由 VLM 验证目标是否存在。 | OpenFrontier。分割与 VLM 目标验证是两个步骤。 |
| P13 RedNet | RGB-D → 语义分割与目标面积 | 为 HM3D Semantics IL 基线提供语义标签和 Semantic Goal Exists 特征。 | HM3D Semantics（作者基线）。使用已有模型；它不是 IL 的 RGB ResNet18 分支。 |
| P14 SuperGlue | 两幅图的关键点特征 → 匹配关系 | TANGO 用跨图像匹配确认目标实例，辅助图像目标导航。 | TANGO。匹配网络，不是独立三维场景编码器。 |
| P15 FrontierNet | RGB → 视觉 frontier 与信息增益 | 从图像提出探索候选，并估计候选能揭示的未知空间；VLM 再评估目标相关性。 | OpenFrontier。OpenFrontier 直接使用预训练权重。 |
| P16 BLIP-2（图文工具） | 图像 + 文字 → 相似度 / 属性 / 回答 | VLFM 用于语义价值，TANGO 用于探索与问答，GOAT 用于生成目标外观属性。 | VLFM、TANGO、GOAT-Bench（数据生成）。完整图文模型；不同用途不代表都在导航中生成回答。 |

## 连接与适配模块

| 编号 / 模块 | 输入 → 输出 | 对应功能 | 使用者与边界 |
|---|---|---|---|
| A01 MLP projector | 视觉 / 三维特征 → 语言模型输入 embedding | 对齐特征维度与分布，让已有语言模型能够接收视觉或三维 tokens。 | SoftNav、D3D-VLP、JanusVLN、Uni-NaVid。SoftNav、Uni-NaVid 等训练此连接模块；不等于重新训练编码器。 |
| A02 视觉压缩 / token 合并 | 密集视觉 tokens → 少量历史 tokens | 降低长历史输入成本；AstraNav / SoftNav 使用压缩，Uni-NaVid 使用池化和在线合并。 | SoftNav、AstraNav-Memory、Uni-NaVid。包含不同机制，不表示三篇使用相同压缩权重。 |
| A03 空间 / 坐标 MLP | 坐标 / 距离 / 方向 → 空间 embedding | 把相对位置或目标坐标接入模型，使空间 tokens 和动作候选可被联合处理。 | D3D-VLP、OmniNav、Dynam3D。D3D-VLP、Dynam3D、OmniNav 的具体设计不同。 |
| A04 LoRA | 基础模型 + 低秩增量参数 → 适配后的模型 | 用少量增量参数调整已有模型；基础权重冻结并不意味着有效模型行为不变。 | SoftNav、CompassNav、SG3D / SG-LLM（SG-LLM）。适配范围按论文记录；CompassNav 视觉分支的具体范围仍未明确。 |

## 逐篇论文的训练与来源

### MTU3D

**编码 / 感知：**DINO [E03] + FastSAM [P11]；稀疏 U-Net [E09] 编码几何；CLIP [E02] 编码目标。

**表征 / 连接：**PQ3D 风格 decoder [E17] → 物体 / frontier queries；动态空间记忆合并物体。

**决策：**Spatial Reasoning Transformer → 选择物体或探索前沿 → 局部执行。

**训练：**感知 query proposal 先训练后冻结；后续训练空间推理。底层 DINO / CLIP / U-Net 的逐阶段更新范围未明确。

**来源：**[原文](../04_三维空间表征与目标推理/2025_ICCV_MTU3D_Move_to_Understand_a_3D_Scene.pdf)；§3.1–3.4；PDF p.4–6。

### SoftNav

**编码 / 感知：**在线三维后端 [E18] → 768 维物体 / frontier queries；DINOv3 [E04] → 图像特征。

**表征 / 连接：**MLP [A01]：768→2048；压缩 [A02]：16 帧×15 tokens；三维 / 视觉两路联合输入。

**决策：**Qwen2.5-VL-3B → 探索坐标 → 合格 frontier → GreedyGeodesicFollower。

**训练：**冻结三维后端、视觉骨干和 VLM 基础权重；训练 projector + LoRA [A04]。导航策略共享，三维后端权重按基准选择。

**来源：**[原文](../04_三维空间表征与目标推理/2607.14586v1.pdf)；§III–IV-A；PDF p.2–4。

### MSGNav

**编码 / 感知：**YOLO-World [P01] 检测 + SAM [P09] 分割；CLIP / OpenCLIP [E02] 编码物体。

**表征 / 连接：**三维物体节点 + 共现图像边 → 关键子图；决策记忆与词表更新。

**决策：**GPT-4o（另评估 Qwen-VL-Max）→ 目标 / frontier；VVD 选择可见视点。

**训练：**预训练感知与 VLM 直接调用；没有导航专用微调。闭源 VLM 的内部编码器未公开。

**来源：**[原文](../04_三维空间表征与目标推理/2026_CVPR_MSGNav.pdf)；§3.2–4.1；PDF p.4–6；作者附录 §6.3。

### D3D-VLP

**编码 / 感知：**Dynam3D encoder [E19] → 全景 patch / instance / zone 三层特征。

**表征 / 连接：**空间 MLP [A03] + projector [A01]；CoT 历史；学习式 waypoint 候选。

**决策：**NVILA-Lite-2B → 计划；grounding head → 物体；navigation head → waypoint。

**训练：**SLFS 联合训练规划 / 定位 / 导航，并训练 waypoint predictor。Dynam3D encoder 在本论文中是否更新未明确。

**来源：**[原文](../04_三维空间表征与目标推理/2026_CVPR_D3D-VLP.pdf)；§3–4.1；PDF p.3–6。

### AstraNav-Memory

**编码 / 感知：**冻结 DINOv3 [E04] → PixelUnshuffle / Conv [A02] → Qwen 原生 ViT [E06]。

**表征 / 连接：**压缩视觉 tokens + 带位姿历史图像 → 长时图像记忆。

**决策：**Qwen2.5-VL-3B → 导航坐标 → 局部执行。

**训练：**冻结 DINOv3；训练压缩模块并微调 Qwen。后续 ViT 逐层冻结范围未明确；正文 / 附录 DINO 型号命名不一致。

**来源：**[原文](../05_视觉语言动作决策与视频记忆/2026_CVPR_AstraNav-Memory.pdf)；§3–4.1；PDF p.4–5；附录 p.11。

### JanusVLN

**编码 / 感知：**语义：Qwen 原生视觉 encoder [E06]；空间：VGGT encoder + decoder [E07]。

**表征 / 连接：**两路 KV 记忆 + 投影 / 空间感知融合 [A01]。

**决策：**Qwen2.5-VL-7B 语言主干 → 离散导航动作。

**训练：**明确冻结语义和空间编码器；只微调 LLM 与 projection layer。DINOv2 / SigLIP 2 仅为替换消融。

**来源：**[原文](../05_视觉语言动作决策与视频记忆/ICLR-2026-janusvln-decoupling-semantics-and-spatiality-with-dual-implicit-memory-for-vision-language-navigation-Paper-Conference.pdf)；§3.3–4.1；PDF p.6–7。

### Uni-NaVid

**编码 / 感知：**EVA-CLIP [E05] 编码视频帧；当前 / 短期 / 长期视觉 tokens。

**表征 / 连接：**池化与在线 token 合并 [A02] → MLP projector [A01] → 指令联合输入。

**决策：**Vicuna-7B → 动作序列或语言回答。

**训练：**Stage 1 只训练 projector；Stage 2 训练 projector + LLM。原文列出的两阶段训练对象不含视觉编码器。

**来源：**[原文](https://arxiv.org/html/2412.06224v2)；作者 v2 §IV–V；已有作者 PDF p.4–7。

### OmniNav

**编码 / 感知：**Qwen2.5-VL 原生视觉 encoder [E06]；坐标 MLP [A03] 编码坐标模态。

**表征 / 连接：**慢系统：frontier + 长期图像记忆；快系统：短历史融合特征。

**决策：**Qwen2.5-VL-3B-Instruct → 子目标；DiT / flow policy → 连续 waypoints。

**训练：**先 AR 多任务训练，后加入 flow policy 并联合 AR 数据。视觉编码器的具体冻结 / 更新范围未明确。

**来源：**[原文](../05_视觉语言动作决策与视频记忆/2026_ICLR_OmniNav.pdf)；§3 / §4.3；PDF p.3–5、7–8。

### CompassNav

**编码 / 感知：**Qwen2.5-VL-7B 原生视觉 encoder [E06]；深度 / occupancy 生成图像上的动作候选。

**表征 / 连接：**候选箭头 + 当前图像 + 指令 → VLM 候选选择；另有 Stop Agent。

**决策：**Qwen2.5-VL-7B → 候选索引 → 低层运动；Qwen-QvQ 是数据教师。

**训练：**LoRA [A04] SFT 后做 GRPO。Fig.4 两分支标为可训练，但视觉 tower 逐层适配范围未明确。

**来源：**[原文](../05_视觉语言动作决策与视频记忆/2026_ICLR_CompassNav.pdf)；Fig.4 / Implementation / 附录；PDF p.6、8、21。

### VLFM

**编码 / 感知：**BLIP-2 [P16] 图文相似度；YOLOv7 [P02] / GroundingDINO [P03] 检测；Mobile-SAM [P10] 分割。

**表征 / 连接：**深度 / 位姿 → occupancy；语义分数 → value map → frontier。

**决策：**PointNav 深度编码 [E22] + 相对位姿 → 移动动作；骨干型号未细分。

**训练：**感知模型直接调用；语义搜索不做目标任务训练。作者使用 VER 在 HM3D 上训练低层 PointNav。

**来源：**[原文](../02_语义地图与前沿探索/VLFM_Vision-Language_Frontier_Maps_for_Zero-Shot_Semantic_Navigation.pdf)；§IV；PDF p.3–5。

### OpenFrontier

**编码 / 感知：**FrontierNet [P15] → 候选与信息增益；SAM3 [P12] → 候选目标 mask。

**表征 / 连接：**带标记图像 → VLM 目标相关性；全局 frontier 管理与几何过滤。

**决策：**Gemini-2.5-flash 主实验 → frontier / 目标验证；PointNav [E22] → 移动。

**训练：**使用已有 FrontierNet / SAM3 / VLM；不做导航微调。低层复用 VLFM 的 PointNav 权重。

**来源：**[原文](../02_语义地图与前沿探索/2026_RSS_OpenFrontier.pdf)；§III–IV；PDF p.3–6。

### TANGO

**编码 / 感知：**BLIP-2 [P16] 探索 / 问答；CLIP [E02] 分类；OWLv2 / DETR [P05/P06] 检测；SuperGlue [P14] 匹配。

**表征 / 连接：**解释器调用工具；扩展 VLFM 风格特征地图，可针对新目标重算价值。

**决策：**GPT-4o → 可执行程序；已有深度 PointNav [E22] → waypoint 导航。

**训练：**调用已有模型，不做目标任务微调。低层 PointNav 有 HM3D 预训练历史。

**来源：**[原文](../03_大模型规划与工具调用/2025_CVPR_TANGO.pdf)；§3–4；PDF p.3–6。

### MOPA

**编码 / 感知：**MultiON：Faster R-CNN [P07]；ObjectNav：Detic [P08]；深度 PointNav 用 ResNet50 [E15]。

**表征 / 连接：**语义地图记录物体；规则探索 / 目标位置 → PointNav 输入。

**决策：**PointNav：ResNet50 + MLP + LSTM + actor / critic → 移动动作。

**训练：**复用 DD-PPO PointNav。MultiON 检测器离线微调；ObjectNav 的 Detic 冻结调用。

**来源：**[原文](../03_大模型规划与工具调用/2024_WACV_MOPA.pdf)；§4–5.3；PDF p.3–5、8。

### OVSegDT

**编码 / 感知：**冻结 SigLIP [E01] 编码 RGB / 目标文字；ResNet9 [E13] 编码 mask；YOLOE [P04] 提供部署 mask。

**表征 / 连接：**观察 / 目标 / mask / 上一动作 → 历史 Transformer。

**决策：**动作头 / 价值头 / mask 重建头 → 离散导航动作。

**训练：**训练策略与新增 mask 分支，采用 BC / PPO。SigLIP 冻结；使用 YOLOE 预测 mask 不等于微调 YOLOE。

**来源：**[原文](../01_模仿学习与强化学习导航/2026_CVPR_OVSegDT.pdf)；§4.1–5；PDF p.4–8。

### PQ3D

**编码 / 感知：**PointNet++ [E08]、稀疏 U-Net [E09]、多视角 OpenSeg 路径 [E10]；CLIP [E02] 编码提示。

**表征 / 连接：**特征对齐到三维 segments；prompt-guided query decoder [E17] 汇聚信息。

**决策：**mask / 相关性 / 文字输出头 → 分割、grounding、问答等任务。

**训练：**进行三维视觉语言多任务学习。MTU3D 借鉴结构，原始编码器清单不直接等于 SoftNav 后端。

**来源：**[原文](https://arxiv.org/html/2405.11442v2)；原文 §3.1–3.4。

### Dynam3D

**编码 / 感知：**CLIP ViT-L/14 [E02] + FastSAM [P11]；深度 / 位姿把特征投到三维。

**表征 / 连接：**instance / zone encoders 与特征场 [E19] → 三层 tokens；空间 MLP [A03]。

**决策：**LLaVA-Phi-3-mini → 转向 / 移动 / 停止动作。

**训练：**先训练三维 representation model；训练导航 VLM 时保留已预训练表征与特征场，优化语言模型。

**来源：**[原文](https://proceedings.neurips.cc/paper_files/paper/2025/file/e1a1847e39a7b79b41199176b152f0e6-Paper-Conference.pdf)；正式论文 §3 / 训练附录；PDF p.3–7、23。

### HM3D Semantics

**编码 / 感知：**RL：ResNet50 [E15] 编码 RGB-D；IL：ResNet18 [E14] + 深度 ResNet50 + RedNet [P13]。

**表征 / 连接：**RL → LSTM；IL → GRU；modular → SemExp 语义地图 CNN [E21]。

**决策：**DD-PPO / 行为克隆策略 → 动作；SemExp → 探索目标 + 几何规划。

**训练：**数据集本身不带固定编码器。作者训练导航基线；IL RGB 从随机初始化，深度来自 PointNav 预训练，冻结范围未细分。

**来源：**[原文](../00_数据集与任务基准/2023_CVPR_HM3D_Semantics_ObjectNav.pdf)；§4.1–4.3；PDF p.7–8。

### HM3D-OVON

**编码 / 感知：**冻结 SigLIP [E01] 编码观察 / 目标；OD 版本增加 OWLv2 [P05]。

**表征 / 连接：**观察特征 + 上一动作 → 历史 Transformer；OD 可切换到目标接近。

**决策：**BC / DAgger / PPO / DAgRL 等 → 动作；VLFM 对照改用 OWLv2。

**训练：**训练历史策略，SigLIP 冻结。此处的 OWLv2 是 OVON 修改版 VLFM 配置，不是原 VLFM 的检测器。

**来源：**[原文](../00_数据集与任务基准/2024_IROS_HM3D_OVON.pdf)；Policy Architecture / §IV；PDF p.3–6。

### GOAT-Bench

**编码 / 感知：**CLIP-RN50 [E16] + CLIP [E02]；LanguageNav 用 BERT [E11]；ImageNav 用 CroCo-v2 [E12]；modular 用 Detic [P08]。

**表征 / 连接：**分技能 / 单一 GRU：隐式记忆；Modular GOAT：语义与实例地图；数据生成用 BLIP-2 [P16]。

**决策：**SenseAct-NN 策略 → 动作；模块化匹配 → 导航。ChatGPT-3.5 只用于目标描述生成。

**训练：**CLIP、BERT、CroCo-v2 在相应作者策略中冻结；训练 GRU 策略。数据生成模型与在线导航组件分开。

**来源：**[原文](../00_数据集与任务基准/2024_CVPR_GOAT_Bench.pdf)；§4–5 / 附录 C.1；PDF p.4–6、12–14。

### SG3D / SG-LLM

**编码 / 感知：**SG-LLM 用空间 Transformer [E20]；PointNet++ [E08] 明确属于 3D-VG / 纯 LLM 对照；导航用 CLIP [E02]。

**表征 / 连接：**SG-LLM：object tokens + sequential adapter；导航：CLIP 记忆或 GRU 隐藏状态。

**决策：**Vicuna-7B + grounding head → 目标；导航基线单独预测动作。

**训练：**SG-LLM 用 LoRA [A04] 适配。最底层对象 backbone 未明确；端到端导航从 GOAT 策略初始化后微调。

**来源：**[原文](../00_数据集与任务基准/2024_SG3D_Sequential_Grounding_and_Navigation.pdf)；§4–5 / 附录 A.3–4；PDF p.5–6、15–16。
